# 16×16 脉动阵列 (Systolic Array) 设计文档

## 1. 项目概述

本项目实现了一个 16×16 的脉动阵列，用于高效执行矩阵乘法运算 $C = A \times B$，其中 $A$、$B$、$C$ 均为 16×16 矩阵。

### 1.1 设计目标

- **高吞吐量**：利用脉动阵列的并行性，实现高效矩阵乘法
- **流水线设计**：每个 PE 包含 5 级流水线 Booth 乘法器
- **标准接口**：使用 AXI-Stream 接口进行数据输入/输出
- **可扩展性**：参数化设计，支持不同尺寸的阵列

### 1.2 性能指标

| 指标 | 数值 |
|------|------|
| 阵列尺寸 | 16 × 16 = 256 PEs |
| 数据宽度 | 16 位 (有符号) |
| 累加器宽度 | 40 位 |
| 乘法器流水线级数 | 5 级 |
| 单次计算 MAC 操作 | 16 × 16 × 16 = 4096 |

## 2. 架构设计

### 2.1 整体架构

```
                    ┌─────────────────────────────────────┐
                    │           sa16x16_top               │
                    │                                     │
    AXI-Stream A ──►│  ┌─────────┐    ┌───────────────┐  │
                    │  │ mat_a   │    │               │  │
    AXI-Stream B ──►│  │ buffer  │───►│   16×16 PE    │  │──► AXI-Stream C
                    │  │ mat_b   │    │   Array       │  │
                    │  │ buffer  │    │               │  │
                    │  └─────────┘    └───────────────┘  │
                    │        ▲              ▲            │
                    │        │              │            │
                    │        └──────┬───────┘            │
                    │               │                    │
                    │       ┌───────▼───────┐            │

```

### 2.2 PE (Processing Element) 结构

每个 PE 执行 MAC (Multiply-Accumulate) 操作：

```
         a_in ──────┬──────────────────────────────► a_out
                    │
                    ▼
              ┌───────────┐
              │   5-stage │
              │   Booth   │──────┐
              │ Multiplier│      │
              └───────────┘      │
                    ▲            │
                    │            ▼
         b_in ──────┼──────┬─────────┐
                    │      │    +    │──► acc_out
                    │      │         │
                    │      └────▲────┘
                    │           │
                    └───────────┘
                    │
                    ▼
         b_out ◄────┘
```

### 2.3 数据流 (Wavefront Pattern)

脉动阵列采用对角波前数据流：

- **A 矩阵**：从左边缘水平流入，向右传播
- **B 矩阵**：从上边缘垂直流入，向下传播
- **有效信号**：PE[r][c] 在 phase = r + c 时开始接收有效数据

```
Phase 0:    Phase 1:    Phase 2:    Phase 3:
┌─┬─┬─┬─┐  ┌─┬─┬─┬─┐  ┌─┬─┬─┬─┐  ┌─┬─┬─┬─┐
│●│ │ │ │  │●│●│ │ │  │●│●│●│ │  │●│●│●│●│
├─┼─┼─┼─┤  ├─┼─┼─┼─┤  ├─┼─┼─┼─┤  ├─┼─┼─┼─┤
│ │ │ │ │  │●│ │ │ │  │●│●│ │ │  │●│●│●│ │
├─┼─┼─┼─┤  ├─┼─┼─┼─┤  ├─┼─┼─┼─┤  ├─┼─┼─┼─┤
│ │ │ │ │  │ │ │ │ │  │●│ │ │ │  │●│●│ │ │
├─┼─┼─┼─┤  ├─┼─┼─┼─┤  ├─┼─┼─┼─┤  ├─┼─┼─┼─┤
│ │ │ │ │  │ │ │ │ │  │ │ │ │ │  │●│ │ │ │
└─┴─┴─┴─┘  └─┴─┴─┴─┘  └─┴─┴─┴─┘  └─┴─┴─┴─┘
● = PE 正在执行计算
```

## 4. 时序分析

### 4.1 计算阶段时长

对于 N×N 阵列：
- PE[0][0] 在 phase=0 开始计算
- PE[N-1][N-1] 在 phase=2(N-1) 开始计算
- 每个 PE 需要处理 N 个乘加操作
- 乘法器流水线延迟：5 cycles
- **总计算阶段**：3N + 2 cycles

### 4.2 总延迟

| 阶段 | 周期数 (N=16) |
|------|---------------|
| CLEAR | 1 |
| LOAD_A | 256 |
| LOAD_B | 256 |
| COMPUTE | 50 |
| DRAIN | 256 |
| **总计** | **819** |

## 5. 优化建议

### 5.1 A/B 并行加载 ⚠️

**当前实现**：串行加载 A 和 B（先 A 后 B）

**优化方案**：A 和 B 可以同时加载，因为：
1. mat_a 和 mat_b 是独立的存储缓冲区
2. 地址生成逻辑相同
3. 不存在数据依赖

**节省时间**：256 cycles（约 31% 的加载时间）

```systemverilog
// 优化后的状态机
S_IDLE → S_CLEAR → S_LOAD_AB → S_COMPUTE → S_DRAIN → S_DONE
                      ↑
              同时加载 A 和 B
```

### 5.2 流水线输出

当前 DRAIN 阶段是阻塞式输出。可以优化为：
- 计算完成后立即开始输出
- 输出与下一次计算的加载阶段重叠

### 5.3 减小综合规模

16×16 阵列综合时间过长，建议：
1. **使用 4×4 版本进行验证和综合探索**
2. 确认时序和面积后再扩展到 16×16
3. 考虑层次化综合策略
