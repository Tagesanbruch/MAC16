# Exp H/I/J 实验结果汇总

**日期**: 2026-01-26  
**目标**: 功耗 <300µW, 频率 >1GHz @ SS corner, 面积 <8100µm²

## 实验概述

| 实验 | 优化方向 | 核心技术 |
|------|----------|----------|
| Exp H | 操作数隔离 (止血钳) | 乘法器输入寄存器仅在最后一个输入周期更新 |
| Exp I | 有效信号门控 (积少成多) | 流水线寄存器仅在 valid 信号有效时更新 |
| Exp J | 串行-并行乘法器 (釜底抽薪) | 位串行乘法器，每周期处理1位，无 Booth/Wallace |

## TT Corner @ 1GHz 结果

| 指标 | Exp H | Exp I | Exp J | 目标 |
|------|-------|-------|-------|------|
| **WNS (ns)** | -0.067 ❌ | **+0.030 ✅** | -0.147 ❌ | ≥ 0 |
| **TNS (ns)** | -1.263 | **0** | -5.445 | 0 |
| **最大频率** | 937 MHz | **1031 MHz** | 872 MHz | >1000 MHz |
| **面积 (µm²)** | 5692 | 5801 | **3290** | <8100 |
| **Sequential %** | 43.39% | 42.58% | 47.20% | - |
| **功耗 (mW)** | 5.74 | 2.30 | 7.05 | <0.3 |

## 关键发现

### ✅ Exp I - 最佳时序
- **唯一通过 TT corner 1GHz 时序的实验**
- WNS = +0.030 ns，有 30ps 余量
- 功耗从 5.74mW 降到 2.30mW (降低 60%)
- 面积略增 (~2%)

### ⚠️ Exp J - 最小面积
- 面积仅 3290µm²，仅为 Exp I 的 **57%**
- 但时序违例严重 (WNS = -0.147 ns)
- 功耗反而最高 (7.05mW) - 串行架构增加了状态机翻转
- 关键路径：累加器加法链 (24位加法器在1周期完成)

### ❌ Exp H - 效果有限
- 操作数隔离思路正确，但实现不够彻底
- 乘法器内部仍然每周期翻转
- 时序违例 -0.067 ns

## 瓶颈分析

### Exp I 时序通过原因
1. **门控流水线减少组合逻辑深度**：无效周期不驱动数据路径
2. **Booth 编码 + Wallace Tree** 保持高效乘法
3. **3级流水线** 切分关键路径

### Exp J 时序失败原因
```
关键路径: mult_sum[31:0] → CSA → accum[23:0] → prev_product[23:0]
                 ↓
        32位累加在单周期完成，路径过长 (1.09ns)
```

### 功耗问题 (仍未解决)
- 所有实验功耗都超标 10x 以上
- iEDA 报告的功耗是 **无条件全速翻转功耗**
- 实际工作中，有效数据周期仅 16/57，功耗会降低 ~70%
- **但仍无法达到 300µW 目标**

## SS Corner 分析结果 (Exp I)

| Corner | WNS (ns) | TNS (ns) | Max Freq | Status |
|--------|----------|----------|----------|--------|
| TT | +0.030 | 0 | 1031 MHz | ✅ PASS |
| **SS** | **-0.786** | -159.809 | **560 MHz** | ❌ FAIL |

### SS Corner 关键发现
- **SS/TT 降速比**: 1.84x (符合 55nm 工艺特性)
- **实际可达频率**: ~560 MHz @ SS corner
- **目标差距**: 需要 1000 MHz，差距约 44%

### 关键路径 (SS Corner)
```
mode_r_reg_p → accum_23__reg_p
Path Delay: 1.673 ns (目标 1.0 ns)
违例: 0.786 ns
```

## 结论

### 当前状态
1. **TT Corner**: Exp I 通过 1GHz 时序 ✅
2. **SS Corner**: 所有实验均无法达到 1GHz ❌
3. **功耗**: 所有实验均超标 10x 以上 ❌

### 根本问题
**55nm 工艺的 SS corner 特性过于悲观**：
- TT → SS 降速 ~1.84x
- 要在 SS corner 达到 1GHz，需要 TT corner 达到 ~1.84 GHz
- 这对于并行 Booth 乘法器架构几乎不可能

### 可行方案

#### 方案 A: 接受 SS Corner 降频
```
设计目标: SS @ 600MHz, TT @ 1100MHz
功耗会降低约 40%
```

#### 方案 B: 多周期乘法
```
将乘法器拆分为 2 个时钟周期
SS @ 1GHz 可行，但延迟增加
```

#### 方案 C: 重新评估工艺库
```
确认是否需要使用 SS corner
部分设计只需满足 TT corner
```
